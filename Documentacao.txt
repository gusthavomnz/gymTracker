================================================================
GYMTRACKER API - DOCUMENTAÇÃO DE ENDPOINTS
================================================================

Base URL: http://localhost:8080

Autenticação: todas as rotas (exceto /auth/register e /auth/login)
exigem o header:
  Authorization: Bearer <token>

O token é obtido no POST /auth/login.

================================================================
AUTH
================================================================

----------------------------------------------------------------
POST /auth/register
Acesso: público
----------------------------------------------------------------

Request:
{
  "name": "João Silva",
  "email": "joao@email.com",
  "password": "senha123",
  "bodyWeight": 80.5,
  "gender": "M"
}

Response 201:
{
  "id": 1,
  "name": "João Silva",
  "email": "joao@email.com"
}

----------------------------------------------------------------
POST /auth/login
Acesso: público
----------------------------------------------------------------

Request:
{
  "email": "joao@email.com",
  "password": "senha123"
}

Response 200:
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}

EXERCÍCIOS — /exercises
================================================================

----------------------------------------------------------------
GET /exercises
Retorna todos os exercícios cadastrados.
----------------------------------------------------------------

Response 200:
[
  { "id": 1,  "name": "Supino Reto com Barra",     "trainingGroupId": 1 },
  { "id": 2,  "name": "Supino Reto com Halteres",  "trainingGroupId": 1 },
  { "id": 17, "name": "Puxada Pulley Frente",       "trainingGroupId": 2 },
  { "id": 18, "name": "Remada Curvada com Barra",   "trainingGroupId": 2 }
]

----------------------------------------------------------------
GET /exercises/group/{id}
Retorna exercícios de um grupo muscular pelo ID do grupo.
Exemplo: GET /exercises/group/1
----------------------------------------------------------------

Response 200:
[
  { "id": 1, "name": "Supino Reto com Barra",    "trainingGroupId": 1 },
  { "id": 2, "name": "Supino Reto com Halteres", "trainingGroupId": 1 },
  { "id": 3, "name": "Crucifixo com Halteres",   "trainingGroupId": 1 }
]

----------------------------------------------------------------
GET /exercises/search?q={termo}
Busca exercícios por nome. Parcial e case-insensitive.
Exemplo: GET /exercises/search?q=supino
----------------------------------------------------------------

Response 200:
[
  { "id": 1, "name": "Supino Reto com Barra",    "trainingGroupId": 1 },
  { "id": 2, "name": "Supino Reto com Halteres", "trainingGroupId": 1 },
  { "id": 4, "name": "Supino Inclinado",          "trainingGroupId": 1 }
]

----------------------------------------------------------------
GET /exercises/muscle-group/name/{name}
Busca exercícios pelo nome do grupo muscular.
Exemplo: GET /exercises/muscle-group/name/costas
----------------------------------------------------------------

Response 200:
[
  { "id": 17, "name": "Puxada Pulley Frente",     "trainingGroupId": 2 },
  { "id": 18, "name": "Remada Curvada com Barra", "trainingGroupId": 2 }
]

----------------------------------------------------------------
POST /exercises
Cria um exercício personalizado.
----------------------------------------------------------------

Request:
{
  "name": "Rosca Spider",
  "trainingGroupId": 5
}

Response 201:
{
  "id": 118,
  "name": "Rosca Spider",
  "trainingGroupId": 5
}

----------------------------------------------------------------
PUT /exercises/{id}
Atualiza nome ou grupo muscular de um exercício.
Exemplo: PUT /exercises/118
----------------------------------------------------------------

Request:
{
  "name": "Rosca Spider com Barra",
  "trainingGroupId": 5
}

Response 200:
{
  "id": 118,
  "name": "Rosca Spider com Barra",
  "trainingGroupId": 5
}

----------------------------------------------------------------
DELETE /exercises/{id}
Remove um exercício.
Exemplo: DELETE /exercises/118
----------------------------------------------------------------

Response 204: (sem corpo)

SESSÕES DE TREINO — /training-sessions
================================================================

----------------------------------------------------------------
POST /training-sessions
Cria uma sessão de treino. O usuário é vinculado automaticamente.
----------------------------------------------------------------

Request:
{
  "name": "Treino de Costas",
  "tgId": 2,
  "date": "2026-04-24",
  "notes": "Foco em força. Aumentar carga no deadlift."
}

  notes: opcional — pode omitir ou enviar null.
  tgId: ID do grupo muscular (ver GET /exercises para referência).

Response 201:
{
  "tsId": 4,
  "name": "Treino de Costas",
  "date": "2026-04-24",
  "tgId": 2,
  "userId": 1,
  "notes": "Foco em força. Aumentar carga no deadlift.",
  "exerciseSets": []
}

----------------------------------------------------------------
GET /training-sessions/{id}
Retorna sessão completa com todas as séries.
Exemplo: GET /training-sessions/4
----------------------------------------------------------------

Response 200:
{
  "tsId": 4,
  "name": "Treino de Costas",
  "date": "2026-04-24",
  "tgId": 2,
  "userId": 1,
  "notes": "Foco em força. Aumentar carga no deadlift.",
  "exerciseSets": [
    { "tsId": 4, "exerciseId": 17, "setNumber": 1, "reps": 8,  "weight": 80.0  },
    { "tsId": 4, "exerciseId": 17, "setNumber": 2, "reps": 6,  "weight": 90.0  },

}

================================================================
SÉRIES — /exercise-sets
================================================================

----------------------------------------------------------------
POST /exercise-sets
Adiciona uma série a uma sessão existente.
setNumber é calculado automaticamente — não enviar.
----------------------------------------------------------------

Request:
{
  "tsId": 4,
  "exerciseId": 17,
  "weight": 100.0,
  "reps": 6
}

Response 201:
{
  "tsId": 4,
  "exerciseId": 17,
  "setNumber": 4,
  "weight": 100.0,
  "reps": 6
}

  setNumber: contador automático por exercício dentro da sessão.
  Para cada combinação tsId + exerciseId, começa em 1 e incrementa.

================================================================
PERFORMANCE — /performance
================================================================

----------------------------------------------------------------
GET /performance/volume-load/{sessionId}
Volume de carga total de uma sessão (peso × reps por exercício).
Exemplo: GET /performance/volume-load/4
----------------------------------------------------------------

Response 200:
{
  "sessionId": 4,
  "sessionName": "Treino de Costas",
  "totalVolume": 2640.0,
  "volumeByExercise": {
    "Puxada Pulley Frente": 1840.0,
    "Remada Curvada com Barra": 800.0
  }
}

  Fórmula: volume = Σ (peso × repetições) por série.

----------------------------------------------------------------
GET /performance/prs
Recordes pessoais do usuário autenticado (maior peso por exercício).
----------------------------------------------------------------

Response 200:
[
  {
    "exerciseName": "Supino Reto com Barra",
    "weight": 120.0,
    "repetitions": 5,
    "date": "2026-04-10",
    "estimatedOneRepMax": 135.0
  },
  {
    "exerciseName": "Agachamento Livre",
    "weight": 160.0,
    "repetitions": 3,
    "date": "2026-04-18",
    "estimatedOneRepMax": 171.56
  }
]

  estimatedOneRepMax: calculado pela fórmula de Brzycki.

----------------------------------------------------------------
GET /performance/volume-distribution?days={n}
Séries realizadas por grupo muscular nos últimos N dias.
Padrão: days=7
Exemplo: GET /performance/volume-distribution?days=14
----------------------------------------------------------------

Response 200:
{
  "Peito": 18,
  "Costas": 24,
  "Pernas": 30,
  "Ombros": 12,
  "Bíceps": 15,
  "Tríceps": 15
}

----------------------------------------------------------------
GET /performance/1rm-calc?weight={peso}&reps={reps}
Calcula o 1RM estimado para um dado peso e número de repetições.
Exemplo: GET /performance/1rm-calc?weight=100&reps=8
----------------------------------------------------------------

Response 200:
128.57

  Fórmula de Brzycki: 1RM = peso / (1.0278 - 0.0278 × reps)
  Para reps=1, retorna o próprio peso.

================================================================
TEMPLATES — /templates
================================================================

----------------------------------------------------------------
POST /templates
Cria um template de treino com exercícios predefinidos.
----------------------------------------------------------------

Request:
{
  "name": "Push Day",
  "exerciseIds": [1, 3, 5, 34]
}

Response 201:
{
  "templateId": 1,
  "name": "Push Day",
  "exerciseIds": [1, 3, 5, 34]
}

----------------------------------------------------------------
GET /templates/my
Lista os templates do usuário autenticado.
----------------------------------------------------------------

Response 200:
[
  {
    "templateId": 1,
    "name": "Push Day",
    "exerciseIds": [1, 3, 5, 34]
  },
  {
    "templateId": 2,
    "name": "Pull Day",
    "exerciseIds": [17, 18, 19, 22]
  },
  {
    "templateId": 3,
    "name": "Leg Day",
    "exerciseIds": [50, 51, 52, 53, 54]
  }
]

----------------------------------------------------------------
DELETE /templates/{id}
Remove um template. Apenas o dono pode remover.
Retorna 403 se o template pertencer a outro usuário.
Exemplo: DELETE /templates/1
----------------------------------------------------------------

Response 204: (sem corpo)
